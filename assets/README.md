# Assets

This folder contains static files used by the portfolio.

Current expected asset:

- `resume.pdf` — the resume file used by the "Resume" button in the nav and
  the "View résumé" links on the team cards.

Place your combined resume PDF here, named exactly `resume.pdf`.

If you add other static media such as images or icons, keep them in this
folder and update any references in `index.html` or `js/data.js`.
